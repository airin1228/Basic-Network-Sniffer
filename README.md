# CodeAlpha_Basic-Network-Sniffer
A lightweight network packet analyzer that captures and monitors live network traffic. It displays packet details including source/destination IPs, protocols (TCP, UDP, ICMP), timestamps, and packet size, making it ideal for learning networking, troubleshooting, and basic cybersecurity analysis.
